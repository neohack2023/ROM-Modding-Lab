# ROM Modding Lab

A multi-console workspace for **ROM modifications, patch releases, verification, and repeatable emulator tests**. This repository distributes patches only, **not commercial game ROMs**.

## Mods

| Console | Game | Mod | Status |
|---|---|---|---|
| NES | Super Mario Bros. 3 (USA PRG1) | [Three Shields v0.2](patches/nes/super-mario-bros-3/three-shields/README.md) | Community playtest |

## Scope

- NES, SNES, N64 and future console mod projects
- IPS / BPS / other patch formats with source-revision hashes
- Emulator test fixtures, reproducible verification scripts and QA receipts
- Shared build/packaging utilities, without bundling proprietary assets

## Safety and distribution

No original or modified commercial ROMs, BIOSes, licensed art dumps, save files with embedded proprietary content, or private machine paths. Use an independently sourced, correctly matching ROM and verify checksums before patching.

## Host 02

Host 02 remains the execution workspace for source disassemblies, native emulator tests, internal datasets, and raw evidence. Only reviewed, releasable artifacts are published here.
